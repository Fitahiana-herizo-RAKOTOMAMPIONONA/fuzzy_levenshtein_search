# fuzzy_levenshtein_search

Un package Dart léger permettant d’effectuer une recherche approximative (fuzzy search) grâce à l’algorithme de distance de Levenshtein.

Parfait pour implémenter une recherche tolérante aux fautes de frappe, des systèmes de suggestions ou d'autocomplétion intelligente.

---

## ✨ Fonctionnalités

- 🔍 Recherche approximative dans une liste de chaînes
- 🧠 Tolérance aux fautes de frappe via la distance de Levenshtein
- 🔡 Sensibilité à la casse activable/désactivable
- 🎯 Résultats triés par pertinence (distance croissante)
- ⏱ Possibilité de limiter le nombre de résultats retournés

---
